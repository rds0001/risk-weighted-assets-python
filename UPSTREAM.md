# Upstream provenance

This distribution was derived from the approved public-release snapshot of
[`rds0001/risk-weighted-assets`](https://github.com/rds0001/risk-weighted-assets):

- upstream commit: `95a159e6046afdf9e58899a1af5543d01cbf7601`
- package baseline: 13 September 2026
- package version: `1.0.0`

The calculation methodology, canonical Excel contracts, synthetic reference data,
reference outputs and documentation were retained. Repository-specific launchers and
filesystem assumptions were replaced by installable entry points, package resources,
a writable workspace abstraction and a stable public Python API.

The RWA construction scaffold and downloaded third-party publications are deliberately
excluded. Source metadata, official links and checksums remain available in the package.
